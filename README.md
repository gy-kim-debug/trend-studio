# Trend Studio

ChatGPT가 정리한 뉴스 원고를 인스타그램 4:5 카드뉴스로 편집하는 Next.js MVP입니다.

## 현재 기능

- 5장 카드뉴스의 제목/본문 편집
- 3종 비주얼 테마 선택
- 1080 × 1350 비율 미리보기
- PNG 개별 다운로드 및 ZIP 일괄 다운로드
- 샘플 콘텐츠 복원

## 실행

Node.js 20 이상에서 `npm install`, `npm run dev`를 실행합니다.

## 범위

v0.1은 브라우저에서 PNG를 생성합니다. 별도의 이미지 렌더링 서버, 저장소, ChatGPT 자동 수집 및 Instagram 게시 연동은 후속 단계입니다. 사용자 입력은 브라우저 메모리에서만 관리되며 새로고침하면 초기화됩니다.
